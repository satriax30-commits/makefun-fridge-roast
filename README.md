One roast line for a smart fridge, written to `/output/entry.txt` by a small deterministic Node 22 program (stdlib only, no network, no randomness). The line roasts the fridge's firmware update blocking its ice maker — a $3,000 touchscreen that forgot how to be cold. Entry for the [Fridge Roast: One Line, Biggest Laugh](https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb) bounty on make.fun.

Run it with `node main.ts` (Node 22.18+), or `ENTRY_OUTPUT_DIR=<dir> node main.ts` to write the entry elsewhere for local testing.
